# نظام خدمات غسيل السيارات

واجهة عربية RTL لإدارة خدمات وحجوزات غسيل السيارات، وتشمل:

- لوحة تشغيل يومية وإحصائيات الحجوزات والإيرادات.
- إنشاء حجز واختيار الخدمة والتاريخ والوقت.
- الدفع بعد الحجز عن طريق الشبكة أو الكاش فقط.
- برنامج ولاء: بعد 3 غسلات مدفوعة تكون الغسلة الرابعة مجانية.
- متابعة الحجوزات والعملاء والخدمات والأسعار.
- تصميم متجاوب مع الجوال والكمبيوتر.

## التشغيل محلياً

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

## النشر على Render

ارفع المشروع إلى GitHub، ثم أنشئ Web Service جديداً في Render واربط المستودع. ملف `render.yaml` يضبط البناء والتشغيل تلقائياً.

يمكن أيضاً إدخال الإعدادات يدوياً:

- Build Command: `npm ci && npm run render:build`
- Start Command: `npm run render:start`
- Node: `22.13.0`

## ملاحظة البيانات

النسخة الحالية واجهة تشغيل تجريبية تحفظ الحجوزات الجديدة داخل جلسة المتصفح. للاستخدام التجاري وربط جميع الأجهزة والموظفين، تُربط الخطوة التالية بقاعدة Supabase لإدارة العملاء والحجوزات وبرنامج الولاء مركزياً.
